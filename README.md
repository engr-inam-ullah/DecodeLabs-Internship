#  To-Do List — DecodeLabs Internship (Project 1)
A simple command-line To-Do List application built in Python as part of the **DecodeLabs Industrial Training Kit — Batch 2026**.
##  About
This project is the first milestone of the internship track. It focuses on core data management using Python **lists** — storing, adding, and displaying multiple items through simple, clear logic.
##  Features
-  Add new tasks
-  View all tasks
-  Mark a task as done
-  Delete a task
- Tasks are saved to `tasks.json` so they persist between runs
##  Tech Stack
- **Language:** Python 3
- **Concepts used:** Lists, loops, `enumerate()`, functions, JSON file handling
##  How to Run
```bash
python To_do_list.py
```
Follow the on-screen menu to add, view, complete, or delete tasks.
# Files
| File | Description |
|------|-------------|
| `To_do_list.py` | Main program |
| `tasks.json` | Stores saved tasks |
